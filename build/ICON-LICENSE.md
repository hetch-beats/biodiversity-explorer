# App icon

`icon.svg`, `icon.png` and `icon.ico` are the Biodiversity Explorer "BE"
monogram. They are original artwork, drawn as plain geometry by
`scripts/generate-icon.mjs`, so there is no font file or third-party artwork
in them.

To the extent possible under law, the authors have dedicated this icon to the
public domain under the Creative Commons CC0 1.0 Universal Public Domain
Dedication: https://creativecommons.org/publicdomain/zero/1.0/

Regenerate with `node scripts/generate-icon.mjs`.
